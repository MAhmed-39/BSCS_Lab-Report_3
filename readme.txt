Geometry Modeling Assignment
This assignment implements Java Point and Triangle classes to demonstrate fundamental OOP concepts.

Concepts Covered
Encapsulation: Private attributes accessed via Public Getters/Setters.

Composition: Triangle uses three Point objects as vertices.

Deep Copying: Copy Constructors prevent unintentional data modification.

Key Calculations
Validity Check: Ensures three points don't form a line.

Geometry: Euclidean Distance (between points), Perimeter, and Area (Heron's Formula).

Run Instructions
Compile and run the single driver file:javac Main.java && java Main
